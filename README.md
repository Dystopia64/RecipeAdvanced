# RecipeAdvanced

Плагин крафта для **Paper 26.1.2**. Java 21, ставится одним файлом — внешних
зависимостей нет.

**Скачать:** [Releases](../../releases/latest)

---

## Возможности

### Редактор прямо в игре

`/ra editor` — рецепты собираются мышью, без правки YAML. Ингредиент кладётся в
слот, результат — в свой; всё остальное настраивается кнопками.

### Ванильные станции

Верстак 3x3, печка, доменная печь, коптильня, костёр, наковальня, точило,
варочная стойка, кузнечный стол, каменотёс, котёл. Рецепты становятся
настоящими рецептами сервера и работают в обычном ванильном окне.

- **печка** — настраивается время плавки, опыт и расход стопки целиком, а не по
  одному предмету за раз;
- **кузнечный стол** — переносит зачарования со старого предмета на новый, а не
  отказывается крафтить зачарованное;
- **котёл** — уровень воды, лавы или снега виден цветными стёклами, под котлом
  должен гореть нужный огонь, у варки есть время, частицы и расход жидкости, а
  результат всплывает из котла. Варка принадлежит блоку: можно уйти, выйти из
  игры и вернуться.

### Свои верстаки на блоках

Любой блок привязывается к своему меню крафта.

### Рецепты по файлам

Один рецепт — один файл в `plugins/RecipeAdvanced/recipes/`, разложенные по
папкам. `/ra save <папка> <рецепт>` перекладывает рецепт, Tab подсказывает
существующие папки.

### `/recipes` — одно дерево на всё

Свои рецепты и рецепты CraftEngine в общем списке с папками. Из рецепта можно
провалиться в рецепт его ингредиента: видно зачарованный меч — нажал на слиток
и увидел, откуда слиток.

### Чужие предметы

CraftEngine, ExecutableItems, ExecutableBlocks, Oraxen, ItemsAdder, MMOItems —
как ингредиенты и как результат. Плагины определяются сами, настраивать нечего.

### Условия рецепта

Право, мир, время суток, требуемый опыт, шанс выпадения, дополнительные
предметы на выходе.

### Проверка

`/ra verify` проходит по всем рецептам и говорит, что с ними не так, — до того
как это заметят игроки.

## Установка

1. Положить jar в `plugins/`.
2. Перезапустить сервер.

Права:

| Право | Кому |
|---|---|
| `recipeadvanced.use` | игрокам: открывать крафты и `/recipes` |
| `recipeadvanced.admin` | администрации: редактор и команды `/ra` |

---

## Команды

| Команда | Что делает |
|---|---|
| `/ra editor` | редактор рецептов |
| `/ra save <папка> <рецепт>` | переложить рецепт в папку |
| `/ra verify` | проверить все рецепты |
| `/ra reload` | перечитать конфигурацию |
| `/recipes` | дерево всех рецептов сервера |

---

## Полная версия

В бесплатной версии нет двух вещей:

- многоблочных станций из блоков — со своим меню, голограммами и частицами;
- верстаков 4x4, 5x5 и 6x6.

Этого кода в бесплатной сборке нет физически: классы не входят в jar.
